# 🛒 eCommerce Demo — Vanilla JS

Multi-page eCommerce demo built with **HTML, CSS, and JavaScript**.  
Designed to showcase real-world frontend structure, UI logic, and state management without frameworks.

## ✨ Features

- Product catalog with categories
- Search and filters
- Product detail page (`?id=`)
- Persistent cart using **LocalStorage**
- Quantity update and item removal
- Order summary and checkout form (demo)
- Responsive layout
- Clean, reusable CSS structure

## 🧠 Concepts Demonstrated

- DOM manipulation
- Modular JavaScript (ES Modules)
- State persistence with LocalStorage
- URL query parameters
- Dynamic rendering from data (JSON-like array)
- Responsive UI with CSS Grid/Flexbox
- Multi-page navigation architecture
